# Paraxe public registry

Generated registry release files, source bundles, and browser previews.

Website: https://tobiwebdeveloper.github.io/paraxe-registry/

The registry distributes editable Vue/React source under MIT. Packages are published separately to npm. Update from the main Paraxe workspace with `pnpm registry:release`, review, then `pnpm registry:deploy`. Versioned release bundles must remain immutable.
