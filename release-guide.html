Source you own.

The registry copies editable files into your IDE project, similar to source-copy component registries. It does not install a remote page or lock your product to this website.

Install

npx @paraxe/cli@0.3.0 add product-page-01 --framework vue --dry-run
npx @paraxe/cli@0.3.0 add product-page-01 --framework vue

The listed npm versions are published. The CLI reports package dependencies; install them separately. Use Node 22 or newer.

Source is copied to blocks/product-page-01/vue/ProductPage01.vue, with shared styles/data next to it. Public images go under public/paraxe/. Full MIT license text goes under .paraxe-licenses/.

Edit locally

Add your own QuantityInput and Add to cart button, connect your cart logic, change media or rearrange the layout. Your changes belong to your app and do not modify other installations. Keep token references so presets continue working.

Style imports

import "@paraxe/design/style.css";
import "./styles/paraxe-preset.css";
import "./styles/paraxe-theme.css";
import "./styles/paraxe-overrides.css";

Use paraxe init or paraxe generate to create project-owned CSS. Overrides load last. Import your chosen block from its copied framework file; its shared CSS is already imported by the block.

Updates and safety

The CLI pins registry 0.1.2, verifies each bundle SHA-256 against its index and each source file against its bundle, rejects unsafe paths and directory links, and refuses existing files unless you explicitly pass --force. Updates never merge or silently replace your edits. Review a dry run and manually merge changes when needed. No registry-provided scripts are executed.

Hashes detect corruption against the selected index; they are not a cryptographic publisher signature. Use the official HTTPS index or a registry you trust. The Paraxe format is its own schema, not a claim of shadcn CLI compatibility.

Host independence

This registry is a static GitHub Pages site. The public release repository and local source keep the complete artifacts. No ChatGPT or Codex session is needed to serve or use them. Moving hosts requires copying the static files and using the CLI's --registry <index-url> option. Keep old versioned paths unchanged.
