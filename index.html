01 / GET STARTED

Bring a block
into your project.

The registry is live. The new npm package versions are prepared for publication by the maintainer. Use the commands below once those versions are available, or download a source bundle now.

npx @paraxe/cli@0.3.0 list
npx @paraxe/cli@0.3.0 add chat-01 --framework vue --dry-run
npx @paraxe/cli@0.3.0 add chat-01 --framework vue
  1. Choose Vue or React. Start with a dry run to review every destination.
  2. Install the package versions reported by the CLI. It never runs package-install scripts.
  3. Import design CSS, generated preset, generated theme, then project overrides. Import the installed block from its framework entry.

Existing files are protected. Use --force only after reviewing replacements. Full licenses are copied alongside installed source.

Package compatibility
  • @paraxe/core@1.4.0
  • @paraxe/design@1.8.0
  • @paraxe/vue@1.3.0
  • @paraxe/react@0.2.0
