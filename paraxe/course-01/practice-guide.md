# Calculus foundations: practice companion

This original sample worksheet accompanies Course01. Replace it with your own learning resources. It is a demonstration, not an assessment or qualification.

1. A function has values f(1) = 1 and f(3) = 9. Find its average rate of change over this interval.
2. For f(x) = x², simplify [f(2 + h) - f(2)] / h for h ≠ 0. What does it approach as h approaches zero?
3. Differentiate x³ using the power rule.
4. Differentiate 3x² + 2x + 1.
5. If position is s(t) = t² metres, find the velocity at t = 3 seconds.
6. Find the stationary point of f(x) = x² - 4x + 5, then explain why it is a minimum.
7. Give an example of a function whose derivative is zero everywhere.
8. Explain the difference between average rate of change and the derivative at a point in one or two sentences.

## Worked guidance

1. (9 - 1) / (3 - 1) = 4.
2. [(2 + h)² - 4] / h = 4 + h, which approaches 4.
3. 3x².
4. 6x + 2.
5. Velocity is s′(t) = 2t, so at t = 3 it is 6 metres per second.
6. f′(x) = 2x - 4 = 0 gives x = 2 and f(2) = 1. The derivative changes from negative to positive there (and f″(x) = 2 > 0), so (2, 1) is a minimum.
7. Any constant function, for example f(x) = 7.
8. An average rate compares two function values over an interval. A derivative describes the limiting rate at a point when that limit exists.
