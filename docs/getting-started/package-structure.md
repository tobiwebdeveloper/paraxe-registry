# Package structure

- `@paraxe/core` exports contracts and types only.
- `@paraxe/vue` exports Vue components and `@paraxe/vue/resolver`.
- `@paraxe/react` exports React components.
- `@paraxe/design` exports token helpers and CSS entry points.

The Vue and React exports differ. Consult the [component index](../reference/component-index.md) before choosing a framework component.
